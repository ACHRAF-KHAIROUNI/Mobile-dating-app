# KoMeet - Instructions 

## 1. Objectif

Le backend KoMeet est fourni. Votre travail consiste à
**l'installer, vérifier qu'il fonctionne, explorer son API, puis
compléter l'application mobile fournie**.

Vous n'avez pas à implémenter le serveur. L'objectif est de vous
concentrer sur Android et Kotlin.

## 2. Préparer l'environnement

Installez et vérifiez les outils suivants :

-   Android Studio, avec un SDK Android compatible avec le projet ;
-   un JDK correspondant à la version indiquée dans le `README.md` du
    backend ;
-   Git ;
-   Postman, pour tester les requêtes HTTP.

Récupérez le dépôt du projet : il contient deux répertoires :

- `back/` : le backend Kotlin / Ktor
- `front/` : le front Android en Kotlin / Jetpack Compose

## 3. Lancer le backend

Suivez les instructions du [back/README.md](./back/README.md) pour :

1.  configurer les variables d'environnement à partir de `.env.example`,
    si nécessaire ;
2.  initialiser la base SQLite et les profils de démonstration ;
3.  démarrer le serveur avec le Gradle Wrapper.
4.  tester l'API avec Postman.


## 4. Commencer le front Android

Une partie du front Android est déjà prête à l'emploi dans le dossier
`front/`. 

Suivez les instructions du [front/README.md](./front/README.md) pour savoir quel travail vous avez à faire.
